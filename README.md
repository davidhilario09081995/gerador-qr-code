# Gerador de QR Code

Gere QR Codes grátis, sem cadastro, sem mensalidade e sem prazo de validade.
O conteúdo fica gravado dentro do próprio QR Code, sem redirecionamento, então ele funciona para sempre.

## Recursos

- QR Code para **link** ou **WhatsApp** (com mensagem pronta)
- Cores, fundo transparente, tamanho e logo no centro
- Download em PNG ou SVG, ou copiar a imagem
- Botão para baixar o QR Code já dentro da arte de avaliação do **Google Meu Negócio**

## Como usar

- **Online:** acesse o endereço do GitHub Pages deste repositório.
- **No computador:** abra o `index.html` no navegador, ou dê dois cliques em `iniciar-servidor.bat` para testar em http://localhost:8080 (e no celular, pelo IP mostrado na janela).

Tudo roda no navegador. Nenhum dado é enviado para servidor.
